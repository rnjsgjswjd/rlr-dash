# 활용 시나리오

> 지역별 자동차보험 손익관리 대시보드 · 자동 생성 문서(2026-10-21) — 원본: `src/docs_data.js`, `src/pipeline.js`

**원칙** — 지역 정보는 손해율 변동 원인을 찾는 탐색·점검·안전 안내 용도로만 씁니다. 지역을 이유로 요율·인수·마케팅을 차등하지 않습니다.

**사용자** — 자동차손익파트 부서원(현재) → 상품·업무·영업·보상 부서(개방 예정)

**기준 주기** — 월 마감

**보고 방식** — 엑셀 A4 인쇄물 + 대시보드 화면 보고(분석 동선)

## A. 손익파트 담당자 — 이번 달 손해율이 왜 올랐나, 어디서 터졌나

- **언제**: 월 마감 직후
- **보는 경로**
  1. 대시보드 KPI(당월·누계)
  2. 월 마감 점검 · 변동 큰 지역(기여 · 최대 사고 영향)
  3. 변동 1위 지역 지도 플로팅
  4. 지역 상세 · 지역 특성
  5. 구성 변화 효과
  6. 당사 사고 · 고액사고 영향(1건 빼면 손해율)
  7. 당사 사고 빈도·심도
- **결과물**: 변동 원인을 지역 → 고액사고 여부 → 채널·담보 → 빈도·심도 순으로 좁혀 설명
- **분석 동선**: 월 마감 점검(기본)

## B. 팀장 · 임원 보고 — 한 장으로 전국 흐름 + 문제 지역 3~5곳 + 이유

- **언제**: 월간 · 분기 보고
- **보는 경로**
  1. 분석 동선으로 화면을 넘기며 보고
  2. 엑셀 보고서(A4)로 출력: 요약·변동 큰 지역·시도별·선택 지역·순위
- **결과물**: 인쇄물(A4)과 화면 보고 두 가지
- **분석 동선**: 월 마감 점검(기본) 복사 → 보고용으로 메모 작성

## C. 보상(클레임) — 튄 손해율이 고액사고 한 건 때문인지, 사고가 주소지 근처에서 나는지, 외부 위험지와 겹치는지

- **언제**: 수시
- **보는 경로**
  1. 당사 사고 · 고액사고 영향(단일 사고 영향 지역)
  2. 지역 선택 → 큰 사고 TOP 5 · 주소지와 거리
  3. 외부 데이터 합치도(TMACS·TAAS·결빙·침수 × 당사 사고)
  4. 대인 피해 정도(경상 비중) · 행정동별 사고 · TAAS 다발지점
  5. 사고경위 분류 · 요일×시간대
- **결과물**: 현장 점검·안전 안내 후보 동네 목록
- **분석 동선**: 보상 점검(직접 만들기)

## D. 채널 · 영업 관리 — 채널별로 손해율이 나쁜 지역, 채널 구성이 다른 지역

- **언제**: 분기
- **보는 경로**
  1. 필터 줄 채널 선택 → 지도·순위
  2. 지역 특성 · 채널별 구성과 손익
  3. 지역코드 점검 · 히스토그램(나누기 = 채널)
- **결과물**: 채널별 관리 대상 지역
- **분석 동선**: 채널 점검(직접 만들기)

## E. 손익 분석(지역코드 적정성) — 같은 지역코드 안에서 튀는 지역, 등급 간 손해율 차이가 유지되는지

- **언제**: 반기 · 연
- **보는 경로**
  1. 지역코드 점검 · 코드별 분포 · 깔때기
  2. 등급 × 채널 히스토그램 · 중앙값 표
- **결과물**: 코드 재검토 후보(원인 확인용)
- **분석 동선**: 지역코드 점검(직접 만들기)

## F. 처음 쓰는 사람(타 부서) — 무엇부터 봐야 하지?

- **언제**: 아무 때나
- **보는 경로**
  1. ▶ 분석 동선 → 월 마감 점검(기본)을 처음부터 따라가기
  2. 각 화면의 ⓘ 공식 버튼으로 지표 뜻 확인
- **결과물**: 대시보드 읽는 순서를 익힘
- **분석 동선**: 월 마감 점검(기본)

## 대시보드 구성(하는 일 순서)

1. **월간 점검(첫 화면)** — KPI · 지도 · 월 마감 ‘변동 큰 지역’(전국 손해율 변동 기여) [A·B·F]
2. **원인 분석(지역 상세)** — 손해율 → 구성(채널·담보) 효과 → 빈도·심도 → 대형사고 → 사고 특성(경상·사고경위·행정동) [A·C]
3. **채널·담보 관점** — 채널을 먼저 고르고 지역을 보는 화면 [D]
4. **지역코드 점검** — 깔때기 · 등급×채널 히스토그램 [E]
5. **외부 환경** — 사고 지역(TAAS·TMACS) · 침수·결빙 [A·C]
6. **출력** — 엑셀 보고서(A4) · 지도 PNG · 분석 동선 파일 공유 [B]

## 앞으로 할 일

- 채널 먼저 보는 화면(시나리오 D)
- 지역코드 점검 기간 비교(시나리오 E)
- 대형사고 비중(상위 사고가 손해액에서 차지하는 몫)
- 행정동·법정동 ‘동 묶어 보기’
- 활용법 영상(분석 동선 자동 재생 녹화)
