# 지표 공식

> 지역별 자동차보험 손익관리 대시보드 · 자동 생성 문서(2026-10-21) — 원본: `src/docs_data.js`, `src/pipeline.js`

대시보드의 모든 금액·손해율은 **필터 범위 안의 합계**로 계산합니다(지역별 손해율의 평균이 아님). 화면의 **ƒx** 버튼에서 같은 내용을 볼 수 있습니다.

## 기본

### 손해율

```
손해율 = 손해액 ÷ 경과보험료 × 100
```

필터 줄의 집계 기간·보종·채널·담보·지역 범위 안에서 합계로 계산합니다(지역별 손해율의 평균이 아님).

### 환산손해율

```
환산손해율 = 손해액 ÷ 환산경과보험료 × 100
```

데이터에 환산경과P 컬럼이 있을 때만 보입니다.

### 전년 동기 대비 · 증감

```
손해율 증감(%p) = 당기 손해율 − 비교기간 손해율
금액 증감률(%) = (당기 금액 ÷ 비교기간 금액 − 1) × 100
```

비교기간은 집계 방식에 따라 전년 같은 달·전년 같은 누계·직전 1년 등으로 정해집니다. 음수는 △로 표시합니다.

### 구성비

```
구성비_j = 항목 j 경과보험료 ÷ 전체 경과보험료
```

채널·담보·보종 구성비는 모두 경과보험료 기준입니다.

### 손해율 수준(매우 낮음~매우 높음)

```
차이 = 지역 손해율 − 전체 손해율
△10%p 이하 매우 낮음 · △10~△3 낮음 · △3~+3 보통 · +3~+10 높음 · +10%p 초과 매우 높음
```

지도 플로팅 창의 꼬리표 기준입니다.

## 월 마감

### 전국 손해율 변동 기여(%p)

```
기여_i = (손해액_i,당기 ÷ 경과P_전체,당기 − 손해액_i,비교 ÷ 경과P_전체,비교) × 100
Σ_i 기여_i = 전체 손해율_당기 − 전체 손해율_비교
```

‘전체’는 필터 범위의 모든 시군구 합계입니다. 기여를 모두 더하면 전체 손해율 변동과 정확히 같으므로, 어느 지역이 전체 변동을 얼마만큼 만들었는지 바로 읽을 수 있습니다. 비교는 전월·전년 동월·누계 전년 세 가지입니다.

## 원인 분해

### 구성 변화 효과 · 항목별 손해율 변화 효과

```
손해율 변동 = 구성 변화 효과 + 항목별 손해율 변화 효과
구성 변화 효과 = Σ_j (s_j,당기 − s_j,비교) × L_j,비교
항목별 손해율 변화 효과 = Σ_j s_j,당기 × (L_j,당기 − L_j,비교)
```

s_j = 항목 j(채널·담보)의 경과P 구성비, L_j = 항목 j의 손해율. 손해율이 높은 항목의 비중이 커져서 오른 것인지, 항목 자체 손해율이 나빠져서 오른 것인지 나눕니다.

## 지역 비교

### 인근 시군구 대비

```
인근 대비(%p) = 지역 손해율 − (Σ 인근 손해액 ÷ Σ 인근 경과P)
```

인근 = 경계가 맞닿은 시군구. 섬처럼 맞닿은 곳이 없으면 계산하지 않습니다(핫스팟 계산에서는 가장 가까운 3곳을 씀).

### 같은 시도 · 인근 · 전국 1곳당 평균

```
1곳당 금액 = 비교 대상 합계 금액 ÷ 지역 수
비교 대상 손해율 = Σ 손해액 ÷ Σ 경과P
```

같은 시도는 선택 지역을 뺀 나머지 시군구입니다.

## 추세

### 12개월 이동 손해율

```
이동 손해율_t = Σ_{k=t−11…t} 손해액_k ÷ Σ_{k=t−11…t} 경과P_k
```

매달 직전 12개월 합계로 계산해 계절 효과를 줄입니다.

### 1년당 추세

```
최근 24개월 월별 손해율 y_t 에 경과P 가중 최소제곱 직선 y = a + b·t 를 맞춤
1년당 추세(%p) = b × 12 × 100
```

월별 손해율의 흔들림을 경과P 크기로 눌러 전체 방향만 봅니다.

## 핫스팟

### 핫스팟(Local Moran's I)

```
z_i = (손해율_i − 평균) ÷ 표준편차
I_i = z_i × (인근 z 평균)
p값 = 인근을 무작위로 999번 바꿔 본 I 중 실제보다 극단인 비율
다중비교 보정(FDR) 선택 시 Benjamini–Hochberg 기준
```

높음–높음 = 나도 높고 주변도 높음(지역적 군집), 높음–낮음 = 나만 높음. 유의수준 기본 5%.

## 지역코드 점검

### 깔때기(같은 코드 안에서 튀는 정도)

```
m = 코드 내 Σ손해액 ÷ Σ경과P
k² = Σ_i EP_i (L_i − m)² ÷ (n − 1)  (|z|>3 지역을 빼고 다시 계산)
z_i = (L_i − m) ÷ (k ÷ √EP_i)
주의: |z| > 1.96 (95%) · 강함: |z| > 3.09 (99.8%)
```

규모가 작은 지역은 원래 많이 흔들리므로 경과P가 클수록 허용 범위가 좁아집니다(과대산포 반영).

### 히스토그램 중앙값 · 가중 손해율

```
관측 1개 = 시군구 × 채널(또는 담보)
중앙값 = 관측 손해율의 가운데 값
가중 손해율 = Σ(손해율 × 경과P) ÷ Σ경과P = Σ손해액 ÷ Σ경과P
```

최소 경과P 미만 관측은 손해율이 크게 흔들려 뺍니다(기본 1억원).

## 당사 사고

### 빈도

```
빈도 = 사고건수 ÷ 경과대수 × 100  (건/100대·년)
경과대수가 없으면: 빈도 = 사고건수 ÷ 경과보험료(억원)
```

사고건수는 사고(접수)번호 기준으로 한 번만 셉니다. 경과대수는 실적 데이터의 담보별 경과대수 중 가장 큰 값을 그 지역의 차량 수로 씁니다. 지역은 피보험자 주소지 기준.

### 심도

```
심도 = 사고 손해액 ÷ 사고건수
사고 손해액 = 손해액, 없으면 지급보험금 + 미결추산액
```

### 지수

```
지수 = 지역 값 ÷ 전국 값 × 100
```

100보다 크면 전국보다 높음. 지도 색은 60 이하~160 이상.

### 손해율 차이 요인(빈도·심도·보험료)

```
손해율 = 빈도 × 심도 × k ÷ 대당 보험료,  k = 실적 손해액 ÷ 사고 손해액
ln(LR_i ÷ LR_0) = ln(F_i ÷ F_0) + ln(S_i ÷ S_0) − ln(P_i ÷ P_0) + ln(k_i ÷ k_0)
각 효과(%p) = (LR_i − LR_0) × 해당 항 ÷ ln(LR_i ÷ LR_0)
```

F 빈도, S 심도, P 대당 경과보험료(경과P ÷ 경과대수), 0 = 전국. 네 효과를 더하면 전국 대비 손해율 차이와 같습니다. ‘기타(k)’는 실적 손해액과 사고 데이터 손해액의 정의 차이입니다.

### 대인 피해 정도 · 경상 비중

```
구간: 사망 / 1~3급 / 4~7급 / 8~11급 / 12~14급
경상 비중 = 12~14급 건수 ÷ 대인 등급 있는 건수
```

### 주소지 ↔ 사고지

```
자기 지역 발생률 = 주소지·사고지가 같은 사고 ÷ 주소지 사고
외부 유입 비율 = 다른 지역 피보험자 사고 ÷ 사고지가 이 지역인 사고
```
