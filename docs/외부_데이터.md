## 자동 갱신 구조

```
매월 3일 03:00(KST) GitHub Actions 'refresh-external'
  1) TAAS API 점검   → ext/api_status.json (유형별 사용 가능/활용신청 필요)
  2) TAAS 수집       → fz/fz_auto_<유형>_<연도>.csv (작년·재작년)
  3) TMACS 수집      → tmacs/tmacs_jijace.csv (2019년~)
  4) 묶음 만들기     → ext/ext_bundle.json · ext/manifest.json · ext/HISTORY.md
```

- 수동 실행: 저장소 Actions → refresh-external → Run workflow (연도·유형 지정 가능)
- 인증키: 저장소 Settings → Secrets → `DATA_GO_KR_KEY` (채팅·메일에 붙여넣지 않음)

## 대시보드에 반영

- **방법 A(권장)**: 관리자가 대시보드를 다시 빌드·배포(`build/sync_ext.py <ext_bundle.json>` → `release.sh`) → 웹·오프라인 모두 내장
- **방법 B(오프라인 PC)**: `ext_bundle.json`을 받아 대시보드 **외부 데이터 → 갱신 파일 불러오기** → 다시 열면 적용(내장 자료보다 새로울 때만)

## 새 유형 추가(결빙·보행노인·보행어린이·자전거·이륜차 등)

1. 공공데이터포털에서 해당 ‘한국도로교통공단 … 사고다발지역’ API 활용신청
2. 다음 자동 수집 때 점검 결과가 ‘사용 가능’이 되면 자동으로 받음
