## 운영 방식

- **초기 적재(한 번)** — 공공데이터포털 API로 과거 자료를 받습니다: GitHub 저장소 Actions → `refresh-external` → Run workflow

```
1) TAAS API 점검   → ext/api_status.json (유형별 사용 가능/활용신청 필요)
2) TAAS 수집       → fz/fz_auto_<유형>_<연도>.csv
3) 기상청 ASOS     → kma/kma_asos_yearly.csv (관측소·연도별 호우일수·결빙위험일수·영하일수·적설일수·한파일수)
4) TMACS 수집      → tmacs/tmacs_jijace.csv
5) 묶음 만들기     → ext/ext_bundle.json · ext/manifest.json · ext/HISTORY.md
```

  관리자가 `build/sync_ext.py <ext_bundle.json>` → `release.sh`로 대시보드에 내장해 배포합니다.

- **매달 갱신 = 값 붙여넣기** — 대시보드 **외부 데이터 → 값 붙여넣기**에서 넣을 곳(침수·결빙·사고 지역)을 고르고 엑셀 표를 붙여넣습니다. 시군구별 값 표(시도·시군구·값) 또는 위치 목록(위도·경도·값). 이 PC 브라우저에 저장되어 다시 열어도 유지됩니다.
- 인증키: 저장소 Settings → Secrets → `DATA_GO_KR_KEY` (채팅·메일에 붙여넣지 않음)
